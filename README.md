# Cricket Match Simulator

An 11-a-side cricket match simulator in Python (5 overs per innings).

## Features
- Two teams of 11 players
- You type in the outcome of every ball
- Two batsmen on the crease at all times
- Strike rotates on odd runs and at the end of every over
- A wicket brings in the next batsman
- Full scorecard at the end of each innings
- Start a new match after the result

## How to run
python "cricket simulator.py"
